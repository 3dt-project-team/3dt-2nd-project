## 5. 응답 품질 비교

### gpt-4.1-mini
- **스타일**: 간결, 4문장
- **장점**: 핵심만 추출, 비용 최저
- **단점**: 구조화 부족, 세부 맥락 미흡
- **투자 시그널**: '관망' — 리스크/매크로 중심
- **분석 품질**: ★★★☆☆

### gpt-5.4-mini (**선정**)
- **스타일**: 마크다운 볼드 + 번호 목록, 5문장
- **장점**: 구조적, FOMC 등 구체적 이벤트 언급, 빠른 응답
- **단점**: gpt-5.4 대비 디테일 약간 부족
- **투자 시그널**: 구체적 + 균형 잡힌 분석
- **분석 품질**: ★★★★☆

### gpt-5.4
- **스타일**: 가장 상세 (510토큰), 퍼센트 인라인 포함, 4문단
- **장점**: CPI 등 세부 매크로 언급, 풍부한 맥락
- **단점**: 응답시간 8.43s (mini 대비 2.9x), 6.2x 비싼 비용
- **투자 시그널**: 매우 상세하고 전문적
- **분석 품질**: ★★★★★

### gpt-5.4-pro
- **상태**: ❌ 401 Unauthorized (구독 키 문제)
- **비고**: 비용이 gpt-5.4의 12x, 테스트 불가
- **평가 유보**

## 7. 최종 선정: `gpt-5.4-mini`

### 선정 근거

1. **최고 속도**: 2.87s로 4개 모델 중 가장 빠름 (gpt-4.1-mini 대비 30% 단축)
2. **우수한 구조화**: 마크다운 서식 + 번호 리스트로 가독성 탁월
3. **합리적 비용**: 호출당 $0.00054로 gpt-4.1-mini ($0.00044) 대비 23% 증가에 불과
4. **충분한 분석 깊이**: FOMC 등 구체적 매크로 이벤트 언급, 실용적 투자 시그널 제공
5. **Responses API 지원**: 최신 API 표준 (`instructions` + `input`) 활용 가능

### 적용 범위

| 적용 대상 | 모델 | API |
|---|---|---|
| Section 8: AI 앙상블 전략 요약 | **gpt-5.4-mini** | Responses API |
| Section 2-2: 키워드 상관 분석 | gpt-4.1-mini (유지) | Chat Completions |
| Section 5: 레짐 해석 | gpt-4.1-mini (유지) | Chat Completions |
| Section 8-1: 멀티모델 비교 | 4개 모델 동시 | 혼합 |

> **참고**: 중간 분석 (Section 2-2, 5)은 비용 효율을 위해 gpt-4.1-mini를 유지합니다.
> AI 최종 전략 보고서 (Section 8)에만 gpt-5.4-mini를 적용하여 품질을 강화합니다.

## 8. 향후 고려사항

- **gpt-5.4-pro 재평가**: 인증 문제 해결 후 품질 비교 필요 (비용 대비 가치 검증)
- **Cached Input 활용**: gpt-5.4-mini는 Cached Input $0.03/1M으로, 반복 실행 시 추가 절감 가능
- **배치 최적화**: 프롬프트 압축 → 토큰 절감 → 비용 최적화 여지 있음
