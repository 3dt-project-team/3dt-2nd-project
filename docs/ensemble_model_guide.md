## 4. ElasticNet 모델 (Step 2)

### 4-1. 모델 선택 이유

| 비교 항목 | RidgeCV (v0412 이전) | ElasticNetCV (v0413~) |
|---|---|---|
| 정규화 | L2만 (계수 축소) | **L1 + L2** (계수 축소 + 선택) |
| 피처 제거 | 불가 — 모든 피처에 비영zero 계수 | **가능** — 불필요 피처를 0으로 |
| 과적합 방지 | 중간 | 강함 (Lasso 효과) |
| 해석 가능성 | 낮음 (모든 계수 0이 아닌 값) | **높음** (살아남은 피처만 해석) |

### 4-2. Time-Decay Weighting

최근 데이터에 더 높은 가중치를 부여하여 **과거 저가 데이터의 편향(Historical Bias)** 을 억제합니다.

$$w_i = \exp\left(-\lambda \cdot (n - i)\right), \quad \lambda = \frac{\ln 2}{\text{half\_life}}$$

| 파라미터 | v0413 | v0414 | 변경 근거 |
|---|---|---|---|
| half_life | 60 거래일 (~3개월) | **30 거래일 (~1.5개월)** | 1년 전 데이터에 과도한 가중치 → 최근 변동성 학습 강화 |

**가중치 감쇠 비교 (v0414, half_life=30):**

| 시점 | 거래일 전 | 가중치 |
|---|---|---|
| 최신 | 0일 | 1.000 |
| 1개월 전 | ~22일 | 0.617 |
| 1.5개월 전 | ~30일 | 0.500 (반감기) |
| 3개월 전 | ~60일 | 0.250 |
| 6개월 전 | ~120일 | 0.063 |
| 1년 전 | ~243일 | 0.004 |

### 4-3. 타겟 변수 전환 (v0414)

| 항목 | v0413 | v0414 |
|---|---|---|
| 타겟 | `close.shift(-20)` (절대가, 원) | `log(close_{t+20} / close_t)` (로그수익률) |
| 문제점 | 삼성(20만)·하이닉스(100만) 스케일 차이 → 하이닉스 R²=-0.33 | 스케일 불변 — 종목 간 동등 학습 |
| 예측 역변환 | 직접 사용 | `pred_price = last_price × exp(pred_log_return)` |

### 4-4. Alpha 범위 제한 (v0414)

| 항목 | v0413 | v0414 |
|---|---|---|
| alphas 파라미터 | `None` (자동 — 결과: 40~189) | `np.logspace(-3, 0, 50)` → **0.001~1.0** |
| 문제점 | alpha=189 → 과잉 정규화 → 모든 계수가 0에 근접 | 적정 정규화 — 최근 변동성 학습 허용 |

### 4-5. 하이퍼파라미터 요약

| 파라미터 | 값 | 설명 |
|---|---|---|
| `l1_ratio` | [0.1, 0.3, 0.5, 0.7, 0.9] | CV가 자동 선택 (0=Ridge, 1=Lasso) |
| `alphas` | `np.logspace(-3, 0, 50)` | 0.001~1.0, 50개 후보 |
| `half_life` | 30 거래일 | Time-Decay 반감기 |
| `cv` | 5-fold | 교차 검증 |
| `max_iter` | 10,000 | 수렴 보장 |
| `random_state` | 42 | 재현 가능성 |

## 5. 동적 가중치 규칙 — 설계 의도 (Step 3)

### 5-1. 설계 철학

> **"Dynamic Weight Interpolation"** — 시장은 이진(Binary)이 아니라 연속(Continuous)입니다.
> RSI 69와 71에서 가중치가 급변하는 것은 비현실적입니다.
> 모든 지표 구간에서 가중치가 부드럽게 전이되도록 설계합니다.

**기본 원칙:**
- Base weight: TimesFM 0.50 / ElasticNet 0.50 (동등 출발)
- 4개 조정 함수가 독립적으로 가중치를 ±조정
- 최종 클리핑: [0.15, 0.85] — 어떤 상황에서도 한 모델이 완전히 무시되지 않음

### 5-2. RSI 가중치 조정 (`_rsi_weight_adjustment`)

**목적**: 과매수/과매도 상태에서 적절한 모델로 가중치를 기울임

**퀀트적 근거**: Wilder(1978)의 RSI는 70 이상에서 과매수, 30 이하에서 과매도를 나타냅니다. 그러나 Hard Threshold(if/else)는 RSI 69.9→70.1에서 가중치가 불연속적으로 점프하는 문제가 있습니다.

**구간별 설계 의도:**

| 구간 | 조정값 | 의도 |
|---|---|---|
| RSI < 30 (극단 과매도) | +0.20 + 가속 보정(최대 +0.10) | 반등 모멘텀이 강할 가능성 → TimesFM(추세) 강화. 극단으로 갈수록 반등 확률 상승 → 가속 |
| RSI 30~50 (약세~중립) | +0.01 × (50 − RSI), 최대 +0.20 | 중립에서 점진적으로 추세 모델 신뢰도 증가. RSI 30에서 +0.20까지 선형 증가 |
| RSI 50 (완전 중립) | 0.00 | 조정 없음 — 두 모델 동등 |
| RSI 50~70 (강세~과매수) | −0.01 × (RSI − 50), 최대 −0.20 | 과매수 접근 시 점진적으로 ElasticNet(회귀) 강화. 과열 조정에 대비 |
| RSI > 70 (극단 과매수) | −0.20 − 가속 보정(최대 −0.05) | 과열 상태에서 평균회귀 압력 극대화. 가속은 완만 → 급격한 전환 방지 |

**수식:**
- 정상 구간(30~70): $\text{adj} = -0.01 \times (\text{RSI} - 50)$, 선형 보간
- 극단 과매도(<30): $\text{adj} = +0.20 + 0.10 \times \min\left(\frac{30 - \text{RSI}}{30}, 1\right)$
- 극단 과매수(>70): $\text{adj} = -0.20 - 0.05 \times \min\left(\frac{\text{RSI} - 70}{30}, 1\right)$

**비대칭 가속 설계 이유:**
- 과매도 가속(+0.10)이 과매수 가속(−0.05)보다 큰 이유: 반도체 섹터 특성상 과매도 후 반등이 과매수 후 하락보다 급격한 경향이 있음 (V자 반등 vs 점진적 조정)

### 5-3. 변동성 가중치 조정 (`_vol_weight_adjustment`)

**목적**: 변동성 레짐 변화를 감지하여 모델 선택에 반영

**퀀트적 근거**: `vol_ratio = realized_vol_5d / realized_vol_20d`는 단기 변동성이 장기 대비 얼마나 높은지를 측정합니다. 급등은 레짐 전환 신호이고, 안정은 추세 지속 환경입니다.

| 구간 | 조정값 | 의도 |
|---|---|---|
| vol_ratio ≤ 0.8 (저변동) | +0.15 × (0.8 − vol)/0.8 | 안정적 환경 → 추세 지속 가능 → TimesFM 강화 |
| 0.8 < vol_ratio < 1.2 (데드존) | 0.00 | 정상 변동성 → 조정 불필요. **노이즈 필터링** |
| vol_ratio ≥ 1.2 (고변동) | −0.20 × min((vol−1.2)/0.8, 1) | 변동성 급증 → 레짐 전환 가능 → ElasticNet(보수적) 강화 |

**데드존(0.8~1.2) 설계 의도:**
- 변동성 비율의 정상 범위. 이 구간에서는 변동성이 의미 있는 신호를 주지 않으므로 묵시적으로 무시
- 불필요한 가중치 변동(whipsaw)을 방지

**비대칭 강도(+0.15 vs −0.20) 설계 이유:**
- 고변동 시 리스크가 더 크므로 보수적 전환(ElasticNet)에 더 강한 가중치를 부여

### 5-4. 이격도 가중치 조정 (`_disparity_weight_adjustment`)

**목적**: 장기 평균(MA120) 대비 괴리가 클수록 평균회귀 압력을 비선형으로 강화

**퀀트적 근거**: 120일 이동평균 이격도가 극단에 도달하면 평균회귀(Mean Reversion) 확률이 비선형적으로 증가합니다. 이격도 10%와 20%의 차이는 단순 2배가 아니라 회귀 압력이 가속됩니다.

| 구간 | 조정값 | 의도 |
|---|---|---|
| disparity > 0 (양의 이격) | $-0.15 \times \min(d/20, 1)^{1.5}$ | 장기 평균 위에 위치 → 하방 회귀 압력. **1.5제곱 가속**: 이격도가 클수록 회귀 압력 급증 |
| disparity < 0 (음의 이격) | $+0.15 \times \min(|d|/10, 1)^{1.5}$ | 장기 평균 아래 → 반등 기대 → 추세 모델 강화 |

**1.5제곱 가속의 의미:**

| 이격도 | 선형 조정 | 1.5제곱 조정 | 차이 |
|---|---|---|---|
| 5% | −0.0375 | −0.0264 | 완만 (일반 영역) |
| 10% | −0.075 | −0.053 | 여전히 완만 |
| 15% | −0.1125 | −0.092 | 가속 시작 |
| 20% | −0.15 | −0.15 | 최대치 도달 |

→ 작은 이격도에서는 조정이 약하고, 극단으로 갈수록 급격히 강해지는 비선형 구조

**양/음 비대칭(d/20 vs |d|/10) 설계 이유:**
- 양의 이격(고평가) 20%까지 최대 조정 → 상승장에서 과도한 보수성을 방지
- 음의 이격(저평가) 10%에서 최대 조정 → 급락 후 반등 기대를 빠르게 반영

### 5-5. 복합 지표 Interaction Term (`_interaction_weight`)

**목적**: 단일 지표만으로 포착하기 어려운 **복합 신호**를 반영

**퀀트적 근거**: RSI 과매수 단독보다 RSI 과매수 + 변동성 급증이 동시에 발생하면 급락 확률이 훨씬 높습니다. 단일 지표의 합보다 복합 효과가 크므로 별도의 Interaction Term이 필요합니다.

| 규칙 | 조건 | 조정값 | 의도 |
|---|---|---|---|
| **과매수 + 고변동** | RSI > 60 AND vol_ratio > 1.2 | −0.10 × strength | 과열 + 불안정 = 급락 위험 ↑ → ElasticNet 긴급 강화 |
| **과매도 + 고변동** | RSI < 40 AND vol_ratio > 1.2 | +0.10 × strength | 공포 매도 + 변동성 = V자 반등 가능 → TimesFM 강화 |
| **이격도 + 과매수** | disparity > 15% AND RSI > 65 | −0.08 × strength | 장기 고평가 + 단기 과열 = 이중 회귀 압력 → ElasticNet 강화 |

**strength 계산**: 각 조건의 초과 정도를 곱하여 신호 강도를 산출

$$\text{strength} = \text{rsi\_strength} \times \text{vol\_strength}$$

- `rsi_strength = min((RSI − 60) / 20, 1)` — RSI가 60을 넘을수록 강도 증가, 80에서 최대
- `vol_strength = min((vol − 1.2) / 0.8, 1)` — vol이 1.2를 넘을수록 강도 증가, 2.0에서 최대

### 5-6. 가중치 합산 및 클리핑

```
w_trend = 0.50 + rsi_adj + vol_adj + disp_adj + interaction_adj
w_trend = clip(w_trend, 0.15, 0.85)
w_meanrev = 1.0 − w_trend
```

**클리핑 범위 [0.15, 0.85] 설계 이유:**
- 어떤 극단 상황에서도 한 모델이 완전히 무시(0%)되지 않도록 보장
- 최소 15%의 가중치는 "반대 의견"으로 리스크 헤지 역할
- v0413의 [0.20, 0.80]에서 확대 → 극단 레짐에서 더 공격적인 포지션 허용

### 5-7. 가중치 규칙 종합 예시

**시나리오 A:** RSI=75, vol_ratio=1.4, disparity=+18%
```
rsi_adj     = -0.20 - 0.05 × min((75-70)/30, 1) = -0.208
vol_adj     = -0.20 × min((1.4-1.2)/0.8, 1)     = -0.050
disp_adj    = -0.15 × min(18/20, 1)^1.5          = -0.117
interaction = -0.10 × (15/20 × 0.25)             = -0.019
────────
w_trend     = 0.50 - 0.208 - 0.050 - 0.117 - 0.019 = 0.106
→ clip(0.106, 0.15, 0.85) = 0.15 (최소값 적용)
→ ElasticNet 85%, TimesFM 15% — 강한 회귀 레짐
```

**시나리오 B:** RSI=25, vol_ratio=0.6, disparity=−12%
```
rsi_adj     = +0.20 + 0.10 × min((30-25)/30, 1) = +0.217
vol_adj     = +0.15 × (0.8-0.6)/0.8              = +0.0375
disp_adj    = +0.15 × min(12/10, 1)^1.5          = +0.150
interaction = +0.10 × (15/20 × 0.75)             = +0.056 (Rule 2)
────────
w_trend     = 0.50 + 0.217 + 0.038 + 0.150 + 0.056 = 0.961
→ clip(0.961, 0.15, 0.85) = 0.85 (최대값 적용)
→ TimesFM 85%, ElasticNet 15% — 강한 추세 레짐
```

## 6. Confidence Score

### 6-1. 산출 로직

신뢰도 점수는 **PI(Prediction Interval) 너비**와 **모델 간 합의도** 두 축으로 구성됩니다.

$$\text{Confidence} = \text{PI Score} + \text{Consensus Score}$$

| 구성 요소 | 배점 | 산식 | 의미 |
|---|---|---|---|
| PI Score | 0~50 | $\min(50, \; 250 / \max(\text{PI\_width\%}, 1))$ | PI 밴드가 좁을수록 예측 정밀도 높음 |
| Consensus | 0~50 | $\max(0, \; 50 \times (1 - \frac{\text{divergence\%}}{20}))$ | 두 모델 예측이 일치할수록 높은 점수 |

### 6-2. 해석 기준

| 점수 구간 | 해석 |
|---|---|
| 80~100 | 높은 신뢰도 — 두 모델 합의 + 좁은 PI |
| 50~80 | 중간 신뢰도 — 부분 합의 또는 중간 PI |
| 20~50 | 낮은 신뢰도 — 모델 간 괴리 또는 넓은 PI |
| 0~20 | 매우 낮음 — 불확실성 높음, 투자 판단 유보 권고 |
