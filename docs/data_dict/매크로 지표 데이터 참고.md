**시계열 정합성 보장(Forward Fill)**, **파생 기술 지표 자동 생산**, 그리고 **지표 확장 무중단 설계**를 적용한 매크로 경제 지표 데이터 스키마를 정리합니다.

반도체 주가 변동성을 예측하기 위한 **'환경 지표'**로서, 글로벌 자본 흐름과 원자재 가격 변동을 일별 시계열로 통합 관리합니다.

## 🗄️ 1. 최종 서빙 DB 스키마 (PostgreSQL 기반)

매크로 지표는 종류와 출처가 다양하므로, **지표 메타데이터(Dimension)**와 **일별 시계열(Fact)**을 분리한 정규화 모델을 채택합니다. 새로운 지표(VIX, KOSPI 등)를 추가할 때 `INSERT` 한 줄이면 되며 스키마 변경이 필요 없습니다.

### 테이블 A: `dim_macro_series` (지표 메타데이터)

| `category` | `VARCHAR(20)` | NOT NULL | `commodity` · `bond` · `currency` · `index` |
| `unit` | `VARCHAR(20)` | NOT NULL | 단위 (`USD/bbl`, `USD/oz`, `%`, `index`) |
| `data_source` | `VARCHAR(30)` | NOT NULL | 데이터 출처 (`yahoo_finance`, `open_exchange_rates`, `fred`) |

### 테이블 B: `fact_macro_daily` (일별 시계열)

| **컬럼명** | **타입** | **필수** | **설명** |

| `high` | `FLOAT` | NULL | 고가 |
| `low` | `FLOAT` | NULL | 저가 |
| `close` | `FLOAT` | NOT NULL | 종가 — 모든 지표의 기본값 |
| `volume` | `BIGINT` | NULL | 거래량 (선물에만 존재) |
| `is_filled` | `BOOLEAN` | NOT NULL DEFAULT false | Forward Fill 보간 여부 플래그 |

Power BI 대시보드와 ML 피처로 직접 활용되는 파생 지표입니다. Databricks Gold 레이어에서 자동으로 연산되어 적재됩니다.

| **컬럼명** | **타입** | **필수** | **설명** |
| --- | --- | --- | --- |
| `id` | `BIGSERIAL` | PK | 자동 증가 |
| `series_id` | `SMALLINT` | FK, NOT NULL | `dim_macro_series.series_id` 참조 |
| `trade_date` | `DATE` | NOT NULL | 기준일 |

### 테이블 D: `fact_macro_fred` (FRED 금리 시계열)

FRED API 반환값은 OHLCV 구조가 아닌 **단일 수치(`rate_value`)**이므로 `fact_macro_daily`와 별도 테이블로 관리합니다.

| **컬럼명** | **타입** | **필수** | **설명** |
| --- | --- | --- | --- |
| `id` | `BIGSERIAL` | PK | 자동 증가 |
| `series_code` | `VARCHAR(20)` | NOT NULL | FRED 시계열 식별 코드 (`DGS10`, `DGS2`, `T10Y2Y`, `BAMLH0A0HYM2`, `DFF`, `DFII10`) |
| `observed_date` | `DATE` | NOT NULL | 금리 값이 관측된 기준 날짜 |
| `rate_value` | `FLOAT` | NOT NULL | 관측일자 기준 금리 수치(%) |
| `is_filled` | `BOOLEAN` | NOT NULL DEFAULT false | Forward Fill 보간으로 채워진 값인지 여부 |

> **UNIQUE 제약:** `(series_code, observed_date)`
> 
> 
> **대상 시계열 6종**
> 
> - `DGS10`: 미국 10년물 국채 금리 — 장기 할인율, 성장주 밸류에이션 역압 핵심 지표
> - `DGS2`: 미국 2년물 국채 금리 — 단기 통화정책 기대치 반영
> - `T10Y2Y`: 장단기 금리차 (10Y−2Y) — 역전(-) 시 경기침체 선행 경고
> - `BAMLH0A0HYM2`: 하이일드 채권 스프레드 — 신용 리스크 프리미엄 급등 시 Risk-off 시그널
> - `DFF`: 실효 연방기금금리 — Fed 실제 기준금리 수준 확인
> - `DFII10`: 10년물 실질금리 (TIPS) — 인플레이션 조정 후 실질 자본비용

> **💡 인덱스 권장사항**
> 
> - `fact_macro_daily`: `trade_date`에 **BRIN 인덱스** (시계열 범위 스캔), `(series_id, trade_date)` UNIQUE
> - `fact_macro_derived`: `(series_id, trade_date, indicator_name)` 복합 인덱스 — BI 슬라이서 쿼리 최적화
> - `fact_macro_fred`: `(series_code, observed_date)` UNIQUE, `observed_date` BRIN 인덱스

| **보고서 섹션** | **사용 테이블** | **표시 내용** | **갱신 주기** |
| --- | --- | --- | --- |
| 매크로 환경 요약 | `fact_macro_daily` + `dim_macro_series` | 7개 지표 전일 대비 등락, Risk-on/Risk-off 구간 판정 | 일별 |
| 파생 지표 대시보드 | `fact_macro_derived` | DXY·Gold 역상관 차트, 원유·구리 동행 차트 | 일별 |
| 환율 변동 알림 | `fact_macro_daily` (FX) | USD/KRW 일간 변동 > 1% 시 경고 | 실시간 |
| 주간 매크로 트렌드 | `fact_macro_derived` | 주간 MA5/MA20 교차 이벤트 요약 (골든/데드 크로스) | 주간 |

| 금리 역전 알림 | `fact_macro_fred` | `T10Y2Y` < 0 진입/이탈 시점 표시, `BAMLH0A0HYM2` > 4% 경고 | 일별 |
