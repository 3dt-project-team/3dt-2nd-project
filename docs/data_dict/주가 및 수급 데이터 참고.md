# 주가 및 수급 데이터 참고

Parent page: 📊 데이터 사전
생성된 시간: 2026년 4월 8일

**ML 타겟 변수 설계**, **한·미 시차 정렬**, 그리고 **다중 시간 프레임 피처 생성**을 적용한 주가 및 수급 데이터 스키마를 정리합니다.

SENSE 프로젝트의 최종 예측 대상인 **반도체 대형주의 하방 리스크(Downside Risk) 및 상승 모멘텀(Upside Momentum)**을 양방향으로 정의하는 핵심 데이터셋이며, 동시에 ML 모델의 **타겟 변수(Y)**와 **정기 보고서(리포트)**의 핵심 지표를 직접 생산합니다.

## 🗄️ 1. 최종 서빙 DB 스키마 (PostgreSQL 기반)

### 테이블 A: `dim_equity` (종목 메타데이터)

| **컬럼명** | **타입** | **필수** | **설명** |
|---|---|---|---|
| `equity_id` | `SMALLINT` | PK | 종목 고유 식별자 (수동 할당) |
| `ticker` | `VARCHAR(20)` | NOT NULL, UNIQUE | Yahoo Finance 티커 (`005930.KS`, `NQ=F` 등) |
| `name_kr` | `VARCHAR(50)` | NULL | 한국어 종목명 |
| `name_en` | `VARCHAR(50)` | NOT NULL | 영어 종목명 |
| `market` | `VARCHAR(10)` | NOT NULL | `KOSPI` · `NASDAQ` · `CME` |
| `asset_type` | `VARCHAR(15)` | NOT NULL | `stock` · `futures` · `etf` |
| `role` | `VARCHAR(20)` | NOT NULL | `target` (예측 대상) · `leading` (선행 지표) |

### 테이블 B: `fact_equity_ohlcv` (일별 OHLCV)

| **컬럼명** | **타입** | **필수** | **설명** |
|---|---|---|---|
| `id` | `BIGSERIAL` | PK | 자동 증가 |
| `equity_id` | `SMALLINT` | FK, NOT NULL | `dim_equity.equity_id` 참조 |
| `trade_date` | `DATE` | NOT NULL | 거래일 |
| `open` | `FLOAT` | NULL | 시가 |
| `high` | `FLOAT` | NULL | 고가 |
| `low` | `FLOAT` | NULL | 저가 |
| `close` | `FLOAT` | NOT NULL | 종가 |
| `volume` | `BIGINT` | NULL | 거래량 |
| `is_filled` | `BOOLEAN` | NOT NULL DEFAULT false | 휴장일 Forward Fill 보간 여부 |

> **UNIQUE 제약:** `(equity_id, trade_date)`

### 테이블 C: `fact_equity_target` (ML 타겟 변수)

이 테이블은 ML 모델의 **타겟 변수(Y)**를 사전 연산하여 저장합니다. **하방 리스크**와 **상승 모멘텀**을 모두 포착하는 양방향 설계입니다. Databricks Gold 레이어에서 일별로 생성됩니다.

| **컬럼명** | **타입** | **필수** | **설명** |
|---|---|---|---|
| `id` | `BIGSERIAL` | PK | 자동 증가 |
| `equity_id` | `SMALLINT` | FK, NOT NULL | `dim_equity.equity_id` (삼성전자·SK하이닉스만) |
| `trade_date` | `DATE` | NOT NULL | 기준일 (T) |
| `return_1d` | `FLOAT` | NOT NULL | T+1일 수익률 (%) |
| `return_5d` | `FLOAT` | NULL | T+5일 누적 수익률 (%) |
| `realized_vol_5d` | `FLOAT` | NULL | T 기준 과거 5일 실현 변동성 |
| `max_drawdown_5d` | `FLOAT` | NULL | T+1 ~ T+5 최대 낙폭 (%) |
| `max_gain_5d` | `FLOAT` | NULL | T+1 ~ T+5 최대 상승폭 (%) |
| `downside_flag` | `BOOLEAN` | NOT NULL | **하방 리스크 트리거**: `max_drawdown_5d < -3%` 시 TRUE |
| `upside_flag` | `BOOLEAN` | NOT NULL | **상승 모멘텀 트리거**: `max_gain_5d > +3%` 시 TRUE |
| `regime` | `VARCHAR(10)` | NOT NULL | `risk` (하방) · `opportunity` (상승) · `neutral` (중립) — 보고서 라벨용 |

> **💡 타겟 변수 설계 근거**
> - `downside_flag` / `upside_flag`는 각각 이진 분류(XGBoost/LightGBM)의 Y 변수로 사용.
> - 임계값 ±3%는 반도체 대형주의 일별 변동성 분포(95th percentile)를 기준으로 설정.
> - `max_drawdown_5d` / `max_gain_5d`는 회귀 모델용 연속 타겟으로 병행 활용 가능.
> - `regime`은 정기 보고서의 **시장 국면 판정**에 직접 사용됨.

### 테이블 D: `fact_equity_signals` (파생 기술 지표)

| **컬럼명** | **타입** | **필수** | **설명** |
|---|---|---|---|
| `id` | `BIGSERIAL` | PK | 자동 증가 |
| `equity_id` | `SMALLINT` | FK, NOT NULL | `dim_equity.equity_id` 참조 |
| `trade_date` | `DATE` | NOT NULL | 기준일 |
| `signal_name` | `VARCHAR(30)` | NOT NULL | `ma_5`, `ma_20`, `rsi_14`, `bollinger_upper`, `bollinger_lower`, `volume_ma_20`, `volume_ratio` |
| `signal_value` | `FLOAT` | NOT NULL | 기술 지표 값 |

> **💡 인덱스 권장사항**
> - `fact_equity_ohlcv`: `trade_date` BRIN, `(equity_id, trade_date)` UNIQUE
> - `fact_equity_target`: `(equity_id, trade_date)` UNIQUE — MLflow에서 학습 데이터 추출 시 직접 조인
> - `fact_equity_signals`: `(equity_id, trade_date, signal_name)` 복합 인덱스

|---|---|---|---|
| **① 양방향 타겟 변수 투명성** | "주가가 오를까 내릴까"를 단일 방향으로만 정의 → 상승 기회 놓침 | `downside_flag` + `upside_flag` + `regime` 을 코드로 명시적 정의, DB에 사전 적재 | 임계값 조정 시 Gold 재연산만으로 전체 파이프라인 재학습 가능. 보고서에 risk/opportunity/neutral 3단계 시장 국면 자동 표기 |

## 🔬 6. 타겟 변수 정의 상세

### 하방 리스크 이진 분류

```
downside_flag = 1  if  min(close[T+1], ..., close[T+5]) / close[T] - 1  < -0.03
               0  otherwise
```

### 상승 모멘텀 이진 분류

```
upside_flag = 1  if  max(close[T+1], ..., close[T+5]) / close[T] - 1  > +0.03
             0  otherwise
```

### 시장 국면 (Regime) 판정

```
regime = 'risk'         if downside_flag = 1 AND upside_flag = 0
         'opportunity'  if upside_flag = 1 AND downside_flag = 0
         'neutral'      otherwise  (양방향 동시 발생 포함)
```

> **양방향 동시 발생**(downside=1 & upside=1)은 고변동성 구간으로, 보고서에서 "High Volatility" 레이블로 별도 표기합니다.

### 연속 타겟 (회귀용)

```
max_drawdown_5d = min(close[T+1:T+5]) / close[T] - 1
max_gain_5d     = max(close[T+1:T+5]) / close[T] - 1
```

### 라벨 분포 예상 (2024년 삼성전자 기준)

| **regime** | **비율** | **건수 (연간)** | **보고서 표기** |
|---|---|---|---|
| `neutral` | ~70% | ~173일 | 🟢 중립 |
| `risk` | ~12% | ~30일 | 🔴 하방 경고 |
| `opportunity` | ~13% | ~32일 | 🟡 상승 기회 |
| `high_vol` (양방향) | ~5% | ~12일 | 🟠 고변동성 주의 |

> **클래스 불균형 대응**: Multi-class 또는 별도 Binary 모델 2개(하방/상승) 병행. SMOTE 또는 XGBoost `scale_pos_weight` 보정. Stratified K-Fold 필수.

## 📝 7. 정기 보고서 연동 설계

관제 시스템이 일별·주별로 자동 생성하는 보고서에서 주가 데이터가 활용되는 주요 섹션입니다.

| **보고서 섹션** | **사용 테이블** | **표시 내용** | **갱신 주기** |
|---|---|---|---|
| 시장 국면 요약 | `fact_equity_target` | `regime` 분포 (최근 5일 중 risk/opportunity/neutral 빈도), 현재 국면 판정 | 일별 |
| 종목별 수익률 히트맵 | `fact_equity_ohlcv` | 타겟+선행 종목 1d/5d/20d 수익률 매트릭스 (색상 코딩) | 일별 |
| 기술 지표 대시보드 | `fact_equity_signals` | MA5/20 골든크로스·데드크로스, RSI 과매수/과매도 구간 | 일별 |
| 주간 요약 리포트 | `fact_equity_target` | 금주 regime 타임라인, 모델 예측 vs 실현 비교 (백테스트 스코어) | 주간 |
| 월간 실적 평가 | `fact_equity_target` + `fact_equity_ohlcv` | 월간 누적 수익률, 최대 낙폭/상승폭, 예측 정확도 추이 | 월간 |
