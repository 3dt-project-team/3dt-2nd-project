# 퀀트 선행 지표 데이터 참고

Parent page: 📊 데이터 사전
생성된 시간: 2026년 4월 8일

**타임존 시프트 보정**, **복합 지수 파생**, 그리고 **비정기 데이터 정합 처리**를 적용한 퀀트 선행 지표 데이터 스키마를 정리합니다.

SENSE 프로젝트의 3대 데이터 축 중 **'알파(Alpha) 지표'**로서, 과거 반도체 사이클 변곡점마다 주가보다 먼저 움직인 4가지 선행 시그널을 수치화합니다. 뉴스 감성(심리)과 매크로(환경)가 포착하지 못하는 **실제 자본의 족적**을 추적합니다.

---

## 🗄️ 1. 최종 서빙 DB 스키마 (PostgreSQL 기반)

4가지 퀀트 지표는 각각 원천 데이터 특성(주기, 스키마, 파생 로직)이 상이하므로, **지표별 독립 팩트 테이블 + 공통 시그널 통합 뷰(View)**로 설계합니다.

### 테이블 A: `fact_quant_sox_sync` (글로벌 피어 동조화)

미국 반도체 지수(^SOX) 및 핵심 종목의 변동이 한국 증시에 전이되는 **스필오버(Spillover) 효과**를 수치화합니다.

| **컬럼명** | **타입** | **필수** | **설명** |
|---|---|---|---|
| `id` | `BIGSERIAL` | PK | 자동 증가 |
| `us_trade_date` | `DATE` | NOT NULL | 미국 거래일 (T) |
| `kr_effective_date` | `DATE` | NOT NULL | 한국 반영일 (T+1 영업일) — 시차 자동 보정 |
| `sox_close` | `FLOAT` | NOT NULL | ^SOX 종가 |
| `sox_return_1d` | `FLOAT` | NOT NULL | ^SOX 일간 수익률 (%) |
| `nvda_return_1d` | `FLOAT` | NULL | NVDA 일간 수익률 (%) |
| `soxl_return_1d` | `FLOAT` | NULL | SOXL 3x 레버리지 수익률 — 변동성 증폭 감지 |
| `correlation_30d` | `FLOAT` | NULL | SOX ↔ SK하이닉스 30일 롤링 상관계수 |
| `spillover_flag` | `BOOLEAN` | NOT NULL | SOX 일간 하락률 > 2% 시 TRUE (한국 하방 경고) |
| `upside_surge_flag` | `BOOLEAN` | NOT NULL | SOX 일간 상승률 > 2% 시 TRUE (한국 상승 모멘텀 신호) |

> **UNIQUE 제약:** `us_trade_date`

### 테이블 B: `fact_quant_memory_proxy` (메모리 기업 Proxy)

접근이 어려운 B2B 메모리 현물가(DRAMeXchange)의 하락 징후를 **순수 메모리 기업(MU, WDC)의 주가**로 대체(Proxy) 추적합니다.

| **컬럼명** | **타입** | **필수** | **설명** |
|---|---|---|---|
| `id` | `BIGSERIAL` | PK | 자동 증가 |
| `trade_date` | `DATE` | NOT NULL, UNIQUE | 미국 거래일 |
| `mu_close` | `FLOAT` | NOT NULL | Micron (MU) 종가 |
| `mu_return_1d` | `FLOAT` | NOT NULL | MU 일간 수익률 (%) |
| `wdc_close` | `FLOAT` | NOT NULL | Western Digital (WDC) 종가 |
| `wdc_return_1d` | `FLOAT` | NOT NULL | WDC 일간 수익률 (%) |
| `memory_sentiment_index` | `FLOAT` | NOT NULL | **복합 지수**: `0.6 × MU_return + 0.4 × WDC_return` (시가총액 가중) |
| `memory_ma5` | `FLOAT` | NULL | `memory_sentiment_index` 5일 이동평균 |
| `memory_trend_flag` | `VARCHAR(10)` | NOT NULL | `bearish` (MA5 하향 3일 연속) · `neutral` · `bullish` |

> **가중치 근거:** MU(DRAM+NAND 통합)가 WDC(NAND 전문)보다 시가총액·메모리 매출 비중이 크므로 0.6:0.4로 가중.

### 테이블 C: `fact_quant_customs` (관세청 10일 수출 통계)

반도체(HS 8542) 수출액을 10일 단위로 추적하여 기업 실적 발표(3개월) 이전에 글로벌 IT 수요 변화를 선행 감지합니다.

| **컬럼명** | **타입** | **필수** | **설명** |
|---|---|---|---|
| `id` | `BIGSERIAL` | PK | 자동 증가 |
| `stat_year` | `SMALLINT` | NOT NULL | 통계 연도 |
| `stat_month` | `SMALLINT` | NOT NULL | 통계 월 |
| `hs_code` | `VARCHAR(10)` | NOT NULL | HS CODE (`8542` = 반도체) |
| `export_usd_amt` | `FLOAT` | NOT NULL | 수출 금액 (USD) |
| `export_qty` | `FLOAT` | NULL | 수출 수량 |
| `yoy_change_pct` | `FLOAT` | NULL | 전년 동월 대비 증감률 (%) |
| `mom_change_pct` | `FLOAT` | NULL | 전월 대비 증감률 (%) |
| `export_trend_flag` | `VARCHAR(10)` | NULL | `declining` (3개월 연속 감소) · `stable` · `growing` |

> **UNIQUE 제약:** `(stat_year, stat_month, hs_code)`

### 테이블 D: `fact_quant_pcr` (Put/Call Ratio)

파생 시장의 거대 자본이 풋옵션(하락 베팅)을 대거 매집하는 징후를 추적하여 **스마트 머니(Smart Money)**의 방향을 선행 포착합니다.

| **컬럼명** | **타입** | **필수** | **설명** |
|---|---|---|---|
| `id` | `BIGSERIAL` | PK | 자동 증가 |
| `trade_date` | `DATE` | NOT NULL, UNIQUE | 거래일 |
| `put_volume` | `BIGINT` | NOT NULL | 풋옵션 총 거래량 |
| `call_volume` | `BIGINT` | NOT NULL | 콜옵션 총 거래량 |
| `pcr_ratio` | `FLOAT` | NOT NULL | `put_volume / call_volume` |
| `pcr_ma5` | `FLOAT` | NULL | PCR 5일 이동평균 |
| `pcr_ma20` | `FLOAT` | NULL | PCR 20일 이동평균 |
| `pcr_breakout_flag` | `BOOLEAN` | NOT NULL | PCR MA5 > MA20 상향 돌파 시 TRUE (하방 경고) |
| `pcr_bullish_flag` | `BOOLEAN` | NOT NULL | PCR MA5 < MA20 하향 돌파 시 TRUE (상승 모멘텀 — 콜 옵션 매집 증가) |

> **💡 인덱스 권장사항 (전체 테이블 공통)**
> - 모든 날짜 컬럼에 **BRIN 인덱스** (시계열 범위 스캔)
> - 각 테이블의 날짜 UNIQUE 인덱스 → 중복 적재 방지
> - `*_flag` 컬럼에 일반 B-tree → Power BI 슬라이서 필터

### 뷰: `v_quant_daily_signals` (통합 시그널 뷰)

4개 퀀트 팩트 테이블을 `kr_effective_date` 기준으로 LEFT JOIN 하여 **일별 통합 퀀트 시그널 대시보드**를 제공합니다.

```sql
CREATE VIEW v_quant_daily_signals AS
SELECT
    d.trade_date,
    sox.spillover_flag,
    sox.upside_surge_flag,
    sox.sox_return_1d,
    sox.correlation_30d,
    mem.memory_sentiment_index,
    mem.memory_trend_flag,
    pcr.pcr_ratio,
    pcr.pcr_breakout_flag,
    pcr.pcr_bullish_flag,
    cust.yoy_change_pct    AS customs_yoy,
    cust.export_trend_flag  AS customs_trend,
    -- 복합 시그널 연산
    CASE
        WHEN sox.spillover_flag AND pcr.pcr_breakout_flag AND mem.memory_trend_flag = 'bearish'
            THEN 'triple_risk'
        WHEN sox.upside_surge_flag AND pcr.pcr_bullish_flag AND mem.memory_trend_flag = 'bullish'
            THEN 'triple_opportunity'
        WHEN sox.spillover_flag OR pcr.pcr_breakout_flag
            THEN 'caution'
        WHEN sox.upside_surge_flag OR pcr.pcr_bullish_flag
            THEN 'promising'
        ELSE 'neutral'
    END AS composite_signal
FROM generate_series(
    (SELECT MIN(trade_date) FROM fact_equity_ohlcv),
    CURRENT_DATE, '1 day'
) AS d(trade_date)
LEFT JOIN fact_quant_sox_sync  sox  ON sox.kr_effective_date = d.trade_date
LEFT JOIN fact_quant_memory_proxy mem ON mem.trade_date = d.trade_date - 1  -- 시차 보정
LEFT JOIN fact_quant_pcr       pcr  ON pcr.trade_date = d.trade_date
LEFT JOIN fact_quant_customs   cust ON cust.stat_year = EXTRACT(YEAR FROM d.trade_date)
                                   AND cust.stat_month = EXTRACT(MONTH FROM d.trade_date);
```

## 🏆 3. 설계 강점 요약

| **핵심 포인트** | **기존 방식의 문제점** | **본 아키텍처의 해결책** | **기대 효과** |
|---|---|---|---|
| **① 타임존 시차 자동 보정** | 미국 ^SOX 종가를 한국 같은 날짜에 조인 → **미래 데이터 유출(Data Leakage)** | `kr_effective_date = us_trade_date + 1 영업일` 자동 매핑 | ML 백테스트 신뢰도 100%, 실제 트레이딩 시나리오와 동일한 정보 환경 재현 |
| **② 비정기 데이터 정합** | 관세청 월별 데이터를 일별 시계열에 억지 조인 → NULL 대량 발생 | 월별 값을 해당 월 전체 영업일에 broadcast → 모든 행에 값 존재 | ML 모델 입력에 결측 없음, BI에서 월간 추세선 자연스럽게 표현 |
| **③ 복합 지수 투명성** | MU, WDC를 개별 피처로 나열 → 모델 복잡도 증가 + 과적합 위험 | `memory_sentiment_index` (시가총액 가중 복합 지수)로 차원 축소 | 피처 수 2 → 1로 축소, 해석 가능한 단일 시그널로 XAI 설명력 극대화 |
| **④ 양방향 선행 지표 경고 시스템** | 각 지표를 개별 대시보드에 시각화 → 교차 신호 놓침 | `v_quant_daily_signals` 뷰에서 `composite_signal` 자동 연산: `triple_risk` / `triple_opportunity` / `caution` / `promising` / `neutral` | Power BI에서 **"하방 3중 경고"** 및 **"상승 3중 신호"** 자동 하이라이트. 정기 보고서의 **퀀트 신호 요약** 섹션에 직접 사용 |
