# git branch protection 설정하기

- dev 직접 push ❌
- PR 없이 merge ❌
- CI 실패하면 merge ❌
- force push ❌

1. `settings` → `branches` → `rules` 선택
2. RuleSet 이름 정하기 ex)Protect dev branch
3. `Enforcement status` Active로
4. `Target Branches`는 Include default branch
5. `Branch Rules` 체크
