# CI/CD 자동화

# **전체 자동화 흐름 (Azure + Terraform 기준)**

## **1️⃣ 코드 Push**

- 개발자가 main 또는 dev 브랜치에 Push / PR
- GitHub Actions 자동 실행

---

## **2️⃣ CI 단계 (Application 검증)**

GitHub Actions가 수행:

- ✅ 코드 Checkout
- ✅ 의존성 설치
- ✅ 테스트 실행
- ✅ 빌드
- ✅ 컨테이너 이미지 생성
- ✅ Azure Container Registry(ACR) 업로드

👉 여기까지는 **애플리케이션 레벨**

---

## **3️⃣ Terraform 실행 (Infra as Code)**

GitHub Actions 안에서:

- terraform init
- terraform plan
- terraform apply

Terraform이 생성하는 것:

- Azure Resource Group
- Azure Container Registry
- Azure Kubernetes Service (AKS) 또는 Azure Container Apps
- 네트워크, 권한, Managed Identity 등

👉 여기까지는 **인프라 레벨**

---

## **4️⃣ Deploy 단계**

- 새 이미지 태그를 AKS / Container Apps에 반영
- Rolling Update 실행
- 서비스 자동 교체

---

## **5️⃣ 운영**

- Azure Monitor / Log Analytics 연동
- 실패 시 이전 이미지로 롤백 가능

```jsx
Developer Push
      ↓
GitHub Actions (CI)
  - Test
  - Build Image
      ↓
Push to Azure Container Registry
      ↓
Terraform (IaC)
  - AKS / Container Apps 생성
      ↓
Deploy (kubectl or Azure deploy action)
      ↓
Production
```
