# 매일매일 작업 시 로테이션

# 0. 원격 저장소의 변경사항 가져오기(필수)

```json
//1. 자신이 현재 작업중인 브랜치 확인
git branch
//2. dev 브랜치가 아닐 경우 이동
git checkout dev
//3. 원격 저장소에서 우리의 로컬 dev 브랜치로 변경사항 가져오기
git pull origin dev
//만약 변경사항이 뭔지만 알고, 변경사항을 현재 내 파일에 적용하고싶지 않다면
git fetch origin dev
git merge origin dev
```

1. 브랜치 생성 ‣ 

```jsx
git branch feat/예시-작성

//혹은 생성 후 바로 이동
git checkout -b feat/예시-작성
```

1. **해당 브랜치 확인 후 이동(정말중요)**

```jsx
git checkout feat/예시-작성

git switch feat/예시-작성

//현재 작업중인 branch 확인
git branch
```

2. 커밋하기 ‣ 

```jsx
//현재 브랜치 상태 체크하기(변경된 파일 확인 등등)
git status

//윈도우 유저 자동줄바꿈 처리
git config --global core.autocrlf true

//변경된 파일 stage
//모든 변경된 파일을 stage할시 git add .
git add [파일이름]

//커밋
git commit -m "feat(docs): added test.txt"
```
